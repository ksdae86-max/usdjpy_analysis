​🛠️ USDJPY 自動分析システム 完全仕様書 (v4.3 最終確定版)
​1. 📂 構成ディレクトリと厳密なファイル管理
​GitHubリポジトリ（mainブランチ）の構造を以下に固定。1文字の齟齬も許容しない。
​■ ルート
​Main.gs: 全体の統合実行エンジン。PropertiesServiceよりURL/SSIDを動的に取得し、各部品を eval() で展開する。
​■ main/ ディレクトリ（自動分析エンジン）
​Config.js: 定数・シート名・閾値。および GUARD 関数群の定義。
​DataRecorder.js: 価格蓄積（100本維持）・数値フィルタ。
​CalcEngine.js: 指標計算（MA/Sigma/RSI 3桁精度固定）。
​MarketGuard.js: 市場開場判定ロジック。
​PositionMonitor.js: ポジション監視（利確/損切/逆クロス）。
​Trend4hAnalyzer.js: 4H環境認識・期待度(★)判定。
​DailyReporter.js: 09:00 日次統計出力。
​Divergence.js: 逆行現象（ダイバージェンス）検知。
​NotifyHandler.js: Discord通知。Webhook URLはスクリプトプロパティから取得。
​■ form/ ディレクトリ（手動入力系）
​Config.js / FormSync.js / AssetRecorder.js / EntryHandler.js / ExitHandler.js / NotifyHandler.js
​2. 📈 数値管理・動作原則（徹底的分析仕様）
​PropertiesServiceによる環境分離: SSID、Discord Webhook URL、GitHubベースURLをコードから完全に排除し、GASのスクリプトプロパティで管理。
​3桁精度の徹底: 価格・乖離・RSI等はすべて toFixed(3) を適用。CONFIG.GUARD.FIXED_STR() により通知・ログの書式を統一。
​数値ガードの標準化: if (CONFIG.GUARD.IS_VALID_NUM(c)) を全モジュールの入り口に配置し、非数値および 0 以下の異常値を排除。
​精神的安定の追求: 通信エラー時は muteHttpExceptions: true により沈黙を守り、メインロジックの完遂を最優先する。
